# Site Starter Template

Un modèle de départ réutilisable pour créer des sites web en HTML, CSS et JavaScript, sans dépendance ni outil de compilation.

## Contenu

- `index.html` : structure HTML de base avec en-tête, navigation, section d’accueil, sections de contenu et pied de page.
- `style.css` : identité visuelle de départ, composants réutilisables et mise en page responsive.
- `script.js` : menu mobile, bascule du thème clair/sombre et année automatique dans le pied de page.
- `.gitignore` : exclusions courantes pour les fichiers locaux et temporaires.

## Utilisation

1. Cliquez sur **Use this template** sur GitHub pour créer un dépôt à partir de ce modèle, ou clonez le dépôt.
2. Remplacez le titre, les textes et les liens dans `index.html`.
3. Personnalisez les couleurs et les espacements au début de `style.css`.
4. Ajoutez vos interactions dans `script.js`.
5. Ouvrez `index.html` dans un navigateur pour prévisualiser le site.

## Publier le site

Vous pouvez héberger ce site statique avec GitHub Pages ou Vercel. Aucun processus de compilation n’est nécessaire.

## Personnalisation

Le modèle utilise uniquement HTML, CSS et JavaScript natifs. Vous pouvez supprimer les sections, renommer les éléments et modifier l’apparence sans dépendance à un projet particulier.
